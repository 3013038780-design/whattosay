# 《中国品酒诗话》逐页阅读记录（进行中）

蔡镇楚著，湖南师范大学出版社，2005 年版。桌面七份 PDF 中本书两份文件哈希相同，作为同一部书阅读。已连续阅读 PDF 第 1—85 页；逐页笔记见 [台账](page-ledger.json)。本书共 332 页，尚未读完。阅读记录不是字句校对、史实核验或正式内容审核。

## 从宴饮诗获得的表达方法

《鹿鸣》《南有嘉鱼》《瓠叶》（PDF 35—36）将待客之诚写在反复咏唱的短句中。祝酒词可以研究这种对称、复沓和节奏，用一处合适的古典引句带出眼前的人与事，再落在容易听懂的祝愿上。薄物共之的谦恭也说明，诚意不必靠奢华措辞支撑。主人宴客与来宾回敬仍要分别整理，不能自动代换身份。

“春酒”的传统意象（PDF 36—37）可以为春日相聚提供文化入口，但春酒酿成季节存在不同旧注，不能把其中一种写成唯一事实。酒的“欢伯”、北斗酌酒等别名与想象（PDF 39—40）有助于写出余味，要与原作语境和当下表达连接，避免生僻名物堆砌。

“与周公瑾交，若饮醇醪，不觉自醉”（PDF 69）关注与人相处的感受，适合作为敬友、赞赏气度的候选方向。正式使用还需核对《三国志》正文与注引来源。朋友局可以说相处之舒畅，不必一概夸地位和功业，也不能预设初识双方已有多年交情。

柏梁体联句（PDF 52—53）、拆字酒令（PDF 55）、兰亭流觞（PDF 79—81）提供互动形式线索：一人接一句、指定韵脚、字形提示、文化答案。小程序中的玩法属于新的产品设计，提供提示和跳过，不让诗词知识或输赢决定饮量。柏梁诗的真伪争论、兰亭真迹流传故事，不因玩法采用而变成已核实历史。

陶潜的重阳、白衣送酒与《饮酒》其五（PDF 84—85）可供秋日雅聚研究。田园闲适、知己怀旧与亲友伤逝是不同情绪；黄公酒垆（PDF 79）涉及亡友，不直接推荐给普通欢乐聚会。

## 诗义与关系的筛选

王翰《凉州词》含有征战的悲壮（PDF 45），荆轲易水送别是生死壮行（PDF 46），苏李别诗有异域难归之痛（PDF 56—57），唐姬饮酒歌是被迫死别（PDF 67—68）。这些作品虽有酒、有慷慨语气，不能作为普通庆功、出差饯行或恋爱局的通用祝福。

《白头吟》（PDF 58）中相守愿望与决绝背景并存。知识卡应说明出处争议和原诗情境，内容选用则考量当下需要，不能截取一句后把整篇描述成婚宴喜诗。太常妻与李白《赠内》（PDF 54—55）涉及夫妻冷落，同样需要排除错误的喜庆匹配。

君臣宴饮、酒诰、晏子、管仲与曹参（PDF 29—43、53）帮助理解古代礼制及政治语境。产品不将其照搬为现代领导局规则。绝缨故事（PDF 47—48）以宽容叙事赞赏君王，却忽略被骚扰者的意愿，不用它教授今天的席间分寸。魏晋避祸、任诞（PDF 70—75）是历史文化对象，不是醉酒、轻慢家人或用饮量证明性格的建议。
