# B04 全书阅读记录

资料：赵惠玲、罗烈文合著《中国酒文化》，336 个 PDF 页面，繁体文本版本。书末版权页（PDF 335—336）记发行日期为 2021 年 11 月第一版；文件名只写赵惠玲，书目以版权页补正。

已连续阅读第 1—336 页，包含封面、目录、全部正文、后记与版权页。已逐批呈现完整页文字并阅读，逐页笔记见 [page-ledger.json](page-ledger.json)。全书阅读已完成，未完成逐字图文校对与史实核验。

## 全书对产品的具体影响

第 58—71 页直接讨论敬酒辞的结构和表达艺术，与用户要求的文采、顺口、文化积累高度相关。这里最有用的观点是：节奏不等于全篇押韵，可以通过短语、结构和语速形成。产品可给出自然断句、递进与呼应，先让听众明白敬谁、为何举杯、祝什么，再用贴切的典故深化情意。

语言的取舍要同时考虑真、短、畅和分寸。赞美过度会让受敬者不安，也会让说话人显得谄媚。即景生情需要现场事实，不能凭日历编造春风、灯光、花园或某道菜；故事引申可以有趣，但不能借笑话跳过真实歉意。

第 84—130 页把新任管理者、婚礼不同角色、升学主持、送别领导、子女祝寿、伴侣生日、好友生日、满月父亲与普通来宾分别列出。数据应记录具体说话人身份，而非只设婚礼、生日、职场三个大类。满月与周岁、主人欢迎与宾客祝福尤其不能混同。

礼俗部分说明历史上的敬酒顺序也有变化，例如岁酒幼先长后与平日尊长在先并非同一种场合。产品不应承诺一套全国通用的酒桌规则。对地区、民族、家庭习惯，保留具体条件；不凭姓名或民族标签推定一个人饮酒、接受亲密接触或遵循某套仪式。

本书既强调不强劝、主随客便，也提供利用面子、集体施压和虚荣心让人不得不喝的方法。这两种立场必须明确取舍。成品服务于缓解词穷和尴尬，采用真诚祝愿、自愿参与、以茶表达和适度幽默；不把成功敬酒定义为让别人喝下去。

## 当前待核问题

- 第 18—24 页：酒旗星记载、猿酒、仪狄杜康、品牌起源及酒史分期混合了传说、推测和历史论述，不直接发布为确定起源。
- 第 26—30 页：香型、葡萄酒糖度与度数、陈藏、黄酒糖量单位等需另查标准，且超出祝酒核心，不据旧书提供现行酒类标准。
- 第 33 页：元代高足杯首次出现等器物史判断需核。不能因书中词语优美就复制到知识卡。
- 第 36、49 页：古典篇名、王安石《元日》题名与字句存在需要校对的疑点。
- 第 52 页：清明、寒食起源与禁火时间混置；历法功能不能照书中概括合并两者。
- 第 53—56 页：历史药酒方和疗效只作理解文化背景，不作为功能推荐或健康宣传。
- 第 58—62 页：敬酒辞起源为推测，元代才出现行令的叙述与其他资料有张力，需核。
- 第 65—67 页：周年庆例文同时写跨年，活动标签须检查多条件，而非照标题分类。
- 第 69—70 页：洒酒例文杯、瓶有混用；事故应先处理和道歉，不要求受影响者接受幽默。
- 第 77—81 页：施压劝酒、编造妻子威胁和秘书代饮，不进入产品默认池。
- 第 87 页：薪火相传引句署为先哲但未给作者，未核前不作认证名言。
- 第 92—93、105、130 页：艺文学会混入工会、受托新郎重复、周岁标满月，说明范文元信息同样需要核对。
- 第 110—112 页：部分婚礼祝词明确涉及教会与圣经，不默认用于所有婚礼。

以上是阅读阶段的研究线索，尚无正式发布内容。原始文件、全文与 OCR 均留本地。

## 第 131—230 页补充

生日与祝寿范例进一步细分了本人、子女、伴侣、普通朋友和新生儿父母的声音。年龄与人生状态必须分开：三十岁不意味着已经结婚、生育、事业稳定；同学重聚也不意味着每个人都取得了同样的成就。推荐内容应给不同生活处境留下余地。

励志与庆功需要不同情感分寸。对失意者的祝福先考虑隐私与感受，不在全桌面前公开恋情挫折、晋升落选或失业细节，也不把低落一律解释为缺乏自信。庆功则感谢具体付出，不能只对成绩加赞美，再要求对方持续奋斗。诗意应表达支持和认可，不能遮盖说教与压力。

聚会、开业、乔迁、迎宾、答谢、节庆、职场和商务范例进一步印证主客有别。来宾道喜不自动变成主人欢迎；获奖者答谢不自动变成总经理号召。乔迁本书也明确反对照书抄袭、空话套话和不合场合的掉书袋。正式内容要保留结构与文化意味，同时改成符合具体身份、可以自然说出口的表达。

新增校核线索：

- 第 151—154、160 页的励志格言、孟子字句、成功之花等引文，仍需逐条查作者与原文，不能未经核验署名。
- 第 162—165 页同学范例含同窗四年、中学、入学十五年和毕业十五年等不一致条件，须做经历与时间一致性检查。
- 第 167—168 页人物标签为新老朋友，正文却预设多年分别；关系分类不能只读标题。
- 第 180—188 页开业、乔迁祝语有生僻或疑似损坏字词，原页与词义未校前不进入候选池。
- 第 185—186 页迁址兼中秋，是双事件范例；不能把每次搬家都配团圆月景。
- 第 206 页月亮最圆及引诗字句需核，日期主题不替代天文学判断。
- 第 224 页初识商务以如胶似漆等形容关系，默认推荐应收敛亲密程度。
- 第 228—230 页车展数据和公司既往经营史为具体事实，开幕不总等于公司首次成立。

## 第 231—336 页补充

本书后半部从闭幕、周年庆典转入潜规则、酒令、游戏、名酒与历史酒局，最后附饮酒养生后记。需要保留的是场景意识与口头文化的创造力，而非将所有旧式要求写成用户必须遵守的规则。

文字酒令中的联句、续句、引用、析字、拆合字、限字、偏旁、谐音和典故，适合继续整理为轻松互动。产品规则属于新的设计：提供提示和跳过，允许看答案后继续，不用知识输赢决定罚酒，不强制亲密接触，不让参与者暴露隐私。复杂牌局和长时间角色游戏超出第一版救急祝酒范围。

诙谐短句也要看关系。第 282 页明确限定熟人轻松局；其中大量诗句被续写、拼接或换字，必须标明改写。第 283—284 页有以茶表达与不以杯中深浅论情意的线索，可以研究轻松、顺口的拒酒和回敬，但不让其他人代为承受饮量。

历史酒局要区分证据层级。鸿门宴可查《史记》；青梅煮酒的展开与蒋干中计属于《三国演义》叙事；杯酒释兵权、千叟宴的具体对白和心理多有改写。知识卡不能把这些内容并列成已经核实的历史原话。
