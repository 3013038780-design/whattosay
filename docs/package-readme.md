# 轮到我了 · 微信小程序试读工程

这是已经构建好的独立工程，不需要在这个文件夹运行npm，也不含原始书籍PDF。

## 本地体验

1. 解压到纯英文路径，例如 /Users/你的用户名/Downloads/whattosay 。本机测试中，含中文的工程路径停在文件加载，纯英文路径可正常运行；建议先用英文目录。
2. 打开微信官方开发者工具。本机已安装在 /Applications/wechatwebdevtools.app 。其他电脑可从官方下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html 。
3. 使用游客模式导入本文件所在的whattosay文件夹，选择“不使用云服务”，运行本次工程即可在模拟器体验。
4. 手机真机预览与公开分享需要登录具有开发权限的微信，并填写自己的真实小程序AppID；不需要AppSecret。游客模式不能上传、发布或证明好友分享成功。

## 怎么用

打开先得到一条有出处的短句。场景一栏可以左右滑动，选择领导同事、朋友、初识、相亲、家宴、迎宾、送别、致谢、回敬或收尾。

职场可选敬全桌或单独敬领导，家宴可选全家或长辈，致谢可选好意或主人款待。切换雅致、诗文、轻松、英文；点“短段版”查看完整一点的表达，点“大字读”方便现场阅读。

“这一句，有来头”能查看原意、书目页码和整理说明。日期、四季、节气可加入开头；以茶代酒也能使用。收藏留在当前设备。分享由使用者主动发起，接收者按版本恢复同一条内容。

当前为52条推荐内容的试读版，另保留3条旧版本供既有分享兼容。文化解释已记录校核范围，仍欢迎现场试读意见。
