# 0.3 诗文扩充与节日匹配记录

日期：2026-10-17。用户要求主动搜集更多诗句，具有一定陌生感、能听懂，也能落到同桌人的时间与心意；明确允许原作中的雪夜与现实天气不同，以《问刘十九》为示例。需求基线见第14节。

## 内容范围

- 新增44处引句、涉及36篇作品、62条完整场景稿。原句、原意、对象、意境、出处和稿件分别登记在`src/data/poetry-expanded.ts`。
- 当前260条推荐，其中112条引句稿；不同引句51处，分为48处古诗／词／现代诗与3处古文。连同备查与历史记录，总库57处引句。
- 五组熟句来源《论语》学而／里仁、王勃天涯若比邻、高适莫愁前路无知己、《诗经》投桃报李的30条稿转为备查。原文保留，旧分享仍可恢复。其他原有文化稿继续推荐。
- 现代诗目前只补入徐志摩《偶然》一处短句；不将它称作已丰富的现代诗库。
- 导出完整库143个引用版本：112条推荐、30条熟句备查、1个历史版本；按体裁统计，不把古文混充古诗，也不把多份改写稿算作多处引句。

## 实现与验证范围

新增夜晚、月色、邀饮待客、好友知己、团圆相聚筛选。换句在适用池内优先遍历不同作品，再使用同源改写；去重历史跨轮保留，避免切换风格后立即重来。

中秋、春节、元宵、重阳按农历识别，排除同月号的闰月。中秋、重阳专用稿只在对应日出现，节日优先于一般轮换；诗中花月是意象，不承诺现场晴朗或真的见月。日期变为普通日时，节日入题恢复为不添加。

自动检查覆盖：跨年中秋日期、闰八月排除、节日稿匹配与伪造日期分享拒绝、意境分享还原、不同作品轮换、连续多轮不重复近期稿、原有分享还原及原生事件。28组全量检查通过，并对最后的节日入题回退做定向检查；类型检查与官方WXML/WXSS编译通过。
