## 来源核查

### r04-ci-12

源释只写夜归/超脱，并以“不鼓励失约夜归或醉酒”为重点，未解释家童熟睡、门外听江声到身不由己/自适的递进。

补全原词内部的情绪转折；后人将不应门比作职场拒绝属于现代借题发挥，不能当作者本意定论。

### r04-shi-357

全文用“鸡鸣㬵㬵”，所供B09 PDF358正文实际为“鸡鸣胶胶”。

按已查看的原页统一胶胶，属于已核原页的字形修录。

### r04-story-09

当前“尤难为坏”不同于部分通行本的“怀”，但所供B08 PDF133正文确实为“壞”。

保留所供本用字，必要时注另本作怀；不能凭熟悉的通行本认定OCR错误。

### r04-story-16

源释“后文亦有折屐表现”，当前展示的本则完整原文没有折屐。

删这半句，或查证《晋书》另载后明说别传，不称本条后文。

### r04-story-21

原事明确只因看到船上有作脍工具而来，不是借食物结交朋友。

元数据可准确介绍任诞真率，但不把本则推荐成现代社交送礼技巧。

### poem-ou-calm

源释“借且共从容邀请自在交谈”容易让读者把从容训成现代镇静。

明确原词留连春风与好时光，再与现代借意分开。

### c06-pine

原意说明没有解开“松风吹解带”的句法，容许正文误写成风解衣带。

说明诗中人临风解带/松风吹拂已松解的衣带；只是取自在，不作脱衣动作建议。

### r04-shi-335

“只用于家人、长期相处”范围仍大于夫妻琴瑟意象的实际适用。

补夫妻关系条件，或普通长辈/家庭推荐换句；全文保留。

### r04-ci-14

原词确是至爱相会，但源释“初识不许诺久长”还不足以让强烈爱情句适合普通初识或全家。

实际推荐限关系合适的爱情表达，普通初识/全家换句。

### r04-ci-28

恋人清晓惜别不宜直接覆盖初次相亲的散席。

区分原词恋情与现代惜别，初次相亲优先轻些的原句。

### r04-story-14

全文是谢安本想慰问失官，谢奉自己转开话题；源释只概括谈话边界，正文借不追问，容易误把谢安说成主动避谈的体贴主角。

明确谢奉自己转题；不在初识场景无故引失官与隐私前提，熟友可借谈天自在。
