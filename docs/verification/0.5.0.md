# 0.5.0 分类与界面验证

## 变更

聚会场合与说话任务独立选择；直接来一句为独立快捷入口。五种场合加未指定模式，共42组场合／任务组合，分别检查三种口味与中英文。口味、语言、饮品、意象、时令折叠在“调整表达”。新增62条完整组合稿，引用已有已核对原作；全部旧材料与来源保持。

首次进入组合时，场合专用稿优先，随后优先轮换不同作品；当日农历节日专用稿仍优先。跨场合共用稿采用人工核对名单；初识不套用熟人关系，结束散席不说“接着吃”。原有ID、版本、分享参数与本机收藏／个人稿存储键保留。

## 验证

- TypeScript及微信官方WXML／WXSS编译检查通过。
- 44项自动测试全部通过，覆盖日期、节气、节日、来源、全部旧版本分享恢复、个人编辑与新分类组合。
