# 小笺的数据说明（试读版）

适用于当前仓库的离线内容版本，更新于2026-10-17。正式发布时，运营主体、联系渠道与微信后台声明仍需由实际发布者核对补齐。

## 使用与保存

无需注册。当前代码不请求手机号、定位、通讯录、相册、相机或麦克风，不接入广告、统计、登录、模型接口或其他远程业务服务。

场景、对象、风格和日期在设备内用于选择祝酒词。收藏保存在当前设备，包含精选内容标识、版本与当时的选项，最多100张；不会自动跨设备同步。可在“我的小笺”移除。

## 复制与分享

点击“复制这句”或“复制出处”时，程序将你选中的公开内容写入系统剪贴板；程序不读取剪贴板。

点击分享按钮时，微信展示分享界面，由你选择是否发送及发送给谁。内容分享路径仅携带精选条目标识、版本、场景、对象类别、风格、长短、饮品选项和所选日期，没有私人姓名、经历或联系方式。首页分享不携带当前条目。

网页版分享按钮复制本地体验链接；与微信卡片分享分开。

## 出处与意见

小程序内的出处按钮复制书目与公开原作链接。网页版可主动打开外部原作页面；外部网站的访问处理由其自身负责。

项目公开说明与问题记录入口：[WhatToSay GitHub仓库](https://github.com/3013038780-design/whattosay)。发布者可在正式上线前增加适合公众用户的联系渠道。后续若增加云端收藏、输入定制或模型服务，应先更新本说明和对应平台声明。

为减少重复推荐，本机另外保存最近看过的精选内容ID（最多500条），不会发送到服务器；收藏与浏览记录使用不同存储项。清除小程序本地数据会同时清除这些记录。浏览历史不随分享参数发送。
