# 运行与交付

## 先体验

在项目根目录运行：

```sh
npm ci
npm run preview
```

浏览器打开 http://127.0.0.1:4173 。网页与原生小程序共用内容、日期、筛选、收藏序列化及分享恢复逻辑。网页中的分享按钮复制体验链接，微信卡片分享要在微信小程序里使用。

## 导入微信开发者工具

```sh
npm ci
npm run build
```

可导入项目根目录进行源码开发；本机中文路径的工具加载有问题，实际运行验证使用纯英文目录的独立包。project.config.json 指向 dist/miniprogram，已配置用户提供的AppID wxe93e3ed037f6fd0c；正式预览与公众分享仍需使用该小程序管理员或有开发权限的微信登录。该ID的权限、主体和后台发布状态尚待实际登录验证。不要填写AppSecret，首版无需云资源或模型密钥。

运行 `npm run package` 可生成已构建的独立导入包 dist/whattosay-mini-program.zip；建议解压到Downloads等英文路径，再导入其中的whattosay文件夹；当前包已配置真实AppID，导入时使用有开发权限的微信登录；需要独立游客体验时另将本地副本AppID设为touristappid。该包仍需要微信开发者工具与实际账号环境，不是扫码即用的已上线小程序。

## 功能与范围

- 11类场景：临场、职场、熟朋友、认识新朋友、相亲约会、家宴、主人迎宾、送别、致谢、回敬与收尾。
- 职场区分敬全桌和单独敬领导。雅致、诗文、轻松、英文可选；诗词素材不足时明确提示并回到合适的编辑文案。
- 中文一句版/短段版、大字阅读、以茶代酒、中英文日期/季节/节气入题。
- 本地收藏最多100张，保存当时内容版本和选项；更换设备不自动同步。
- 当前精选内容分享携带稳定ID、版本、场景与日期，接收后恢复同一条。首页分享不携带当前内容。
- 52个推荐试读条目；另保留4个旧版本兼容分享，所用引句已记录原作核对，其他为阅读方法后的独立整理。出处与审核范围见验证文档。

第一版不调用AI，不要求注册，也不收集手机号、定位、通讯录。小程序首次载入后，核心流程不请求额外后端服务。

## 测试

```sh
npm run typecheck
npm test
```

测试会先构建工程。官方WXML/WXSS格式编译可用 `npm run check:wechat` 复现（需本机官方开发者工具）。工具界面运行、真机、双账号分享需单独验证，详见 verification/engineering-initial.md。

## 内容维护与分享

不要修改已发布内容的ID或原地覆盖某版本的正文。正式发布后的修订应保留旧版本或实现明确迁移；分享参数带版本，不支持的版本须回退提示。当前v1仍为发布前试读开发，尚未对外发布微信版本。

对诗句、故事或其他书籍内容的新增，先记录原页、原作、原意和审核范围，再进入数据文件；原始PDF与整本提取结果继续只保留在本地。
