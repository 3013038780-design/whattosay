# 产品方案

更新：2026-10-16。产品名称暂用 WhatToSay / 轮到我了。

## 目标

用户突然被邀请敬酒或发言时，快速获得能说出口的一句话，减少词穷和临场尴尬。成功标准是用户找到合适内容并完成表达，而非文案越华丽越好。

## 首页与交互

1. 打开即展示通用短句和“救急，轮到我了”按钮，无需登录或填表。
2. 五类快捷场景：领导同事、朋友小聚、认识新朋友、相亲约会、家人长辈。
3. 敬全桌或敬某个人分开选择。“有领导在场”是环境条件，不自动等于敬领导。
4. 展示一条主结果，提供换一句、再短一点、自然一点、幽默、诗意、英文、收藏和大字展示。
5. 称呼和真实感谢事项可选填写，不阻塞第一次出句。

首版风格切换从已审核版本中选择，不能把离线选择展示成已进行了 AI 改写。后续接入 AI 后再提供真正的定制改写。

## 场景规则

| 场景 | 默认表达 | 需要避免 |
| --- | --- | --- |
| 敬领导 | 准确称呼、具体感谢、适度祝福 | 编造栽培经历、过度吹捧、代团队承诺 |
| 同事与领导同桌 | 认可共同付出，兼顾全桌 | 将团队成果全部归于单个人 |
| 年轻朋友聚会 | 自然、轻松、适度幽默 | 嘲讽某人、冒犯隐私 |
| 认识新朋友 | 欢迎认识、轻松交流 | 预设亲密关系 |
| 相亲约会 | 友好、有分寸、有继续认识的空间 | 默认暧昧、催婚、评价外貌 |
| 家人长辈 | 温暖、具体、朴实 | 空泛致辞、未经提供的家庭事实 |

“小朋友们的局”暂按年轻朋友理解；如果用户确指儿童聚会，使用饮料与祝福内容。

## 日期与时令

- 1—31 号：每日主题池，可按日期推荐，也可手动浏览。
- 日期主题不要求全部谐音；不存在的日期不进入当月推荐。
- 四季：春日相逢、夏日热闹、秋日收获、冬日团聚等意象。
- 二十四节气：区分“今天是某节气”和“当前处于某节气期间”。
- 不强行叠加日期、节气、季节和古诗；通常只选一个自然的切入点。
- 相同日期在不同场景下有不同版本。

## 第一版范围

救急入口、五类场景、敬酒对象、短句与风格版本、英文与诗意内容、日期主题、四季和节气推荐、本地收藏、大字卡片。

不要求首次使用提供手机号、头像、位置或联系人。季节与时令采用明确的日历规则，不假称知道用户所在城市天气。

## 后续候选功能

- 回敬一句：接住别人已有的祝福。
- 替我收尾：让临场讲话自然结束。
- 以茶代酒：表达祝福并说明饮品选择。
- 本场不重复：同一设备的本场使用记录避免撞词；跨设备同桌去重需要房间码和云端状态。
- 饭局前准备：收藏三句，进入现场快速查看。
- 抽三个词说祝福：朋友局的可选娱乐功能。
- 英文朗读：用户主动点播，后续接入音频服务并测试噪声环境。

## 内容反馈

提供“太正式”“不自然”“不适合这个场景”“喜欢”四类反馈。首轮重点观察从打开到选中内容的时间、换句次数和场景匹配度；真实用户数据收集另行设计必要性与告知。
