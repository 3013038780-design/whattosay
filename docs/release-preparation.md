## 发布者需要接续的实际操作

1. 登录自己的微信小程序账号；没有账号时在[微信公众平台](https://mp.weixin.qq.com/)按实际主体办理注册，账号身份与协议由本人完成。
2. 已收到并配置AppID wxe93e3ed037f6fd0c，已使用管理员微信登录并成功生成手机预览码，开发预览权限已验证。首版无需AppSecret、支付能力、模型密钥或云开发环境。
3. 在微信开发者工具导入工程，编译并真机预览；两位测试者检查好友及群分享、原句恢复、收藏与字体。
4. 在后台核对名称、简介、服务类目、隐私声明、备案与审核要求，补齐实际运营主体和联系方式；上传体验版并试读。
5. 试读确认后提交微信审核，通过后发布，再检查公众可进入和分享。

管理员登录和真实AppID预览上传已完成；用户已确认0.1手机可打开与点击；0.2本轮修改、双账号分享、体验版、审核与发布继续验证。项目代码推送或网页体验不代表完成微信审核。不是所有条目都需要增加付费服务。
