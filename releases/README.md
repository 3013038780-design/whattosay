# 微信独立试读工程包

whattosay-0.3.0-preview.zip 是预构建导入包，无需npm。建议解压到英文路径后，用微信开发者工具登录管理员或有开发权限的微信后导入其中的whattosay文件夹。

已通过官方格式编译和游客模拟器主要流程验证；工程已配置用户提供的AppID；真机、微信好友/群分享和公开发布仍需实际登录、权限核验与发布流程。

内容、发布准备与验证范围见仓库docs。此目录不包含用户原始PDF、整本提取文本、开发者工具或任何账号凭据。SHA256SUMS记录该包的校验值。

0.2为口语和多样性更新，新增168条完整文案与本机浏览去重；0.1包保留用于历史版本对照。0.2.1恢复原有诗文推荐、默认诗词雅意，并补充韵律和歇后语；0.3扩充44处引句、36篇作品、62条完整稿，支持意境及农历节日；请优先导入0.3包。
