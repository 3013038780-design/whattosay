# WhatToSay · 轮到我了

突然被叫起来说两句，打开就能接住。

面向公众、支持分享给好友和微信群的微信小程序，用于饭局中临时敬酒、回敬和表达祝福。优先让用户迅速得到自然、得体、符合关系的一句话，支持英文、诗意、幽默、日期、四季与二十四节气。

## 当前状态

2026-10-16：完成首轮产品构思和技术方案研究，尚未实现或发布小程序。仓库作为本项目后续文档、代码、决策和更新的统一记录。

## 技术方向

推荐微信原生小程序（TypeScript + WXML + WXSS）；第一版以有文化依据的本地审核句库、规则筛选和本地收藏完成核心闭环。云端内容更新和 AI 改写按阶段加入，后端优先评估微信·云开发。

这一方向是当前推荐，尚未创建云资源、选择付费套餐或绑定模型供应商。GitHub 托管代码与文档；微信用户使用的是单独构建、预览和发布的小程序。
