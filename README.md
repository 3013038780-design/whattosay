# WhatToSay · 轮到我了

突然被叫起来说两句，打开就能接住。

面向公众、支持分享给好友和微信群的微信小程序，用于饭局中临时敬酒、回敬和表达祝福。让用户迅速得到有文采、朗朗上口、有文化依据且符合关系的祝酒词，支持英文、诗意、幽默、日期、四季与二十四节气。

## 体验与运行

```sh
npm ci
npm run preview
```

打开 http://127.0.0.1:4173 。`npm run build` 构建原生工程，微信开发者工具导入仓库根目录；`npm run package` 生成独立导入zip。完整步骤见 [运行说明](docs/run.md)。

网页预览与微信小程序分别验证；网页不能发送微信分享卡片。

## 技术方向

推荐微信原生小程序（TypeScript + WXML + WXSS）；第一版以有文化依据的本地审核句库、规则筛选和本地收藏完成核心闭环。云端内容更新和 AI 改写按阶段加入，后端优先评估微信·云开发。

这一方向是当前推荐，尚未创建云资源、选择付费套餐或绑定模型供应商。GitHub 托管代码与文档；微信用户使用的是单独构建、预览和发布的小程序。
