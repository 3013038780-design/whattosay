# WhatToSay · 轮到我了

突然被叫起来说两句，打开就能接住。

面向公众、支持分享给好友和微信群的微信小程序，用于饭局中临时敬酒、回敬和表达祝福。让用户迅速得到有文采、朗朗上口、有文化依据且符合关系的祝酒词，支持英文、诗意、幽默、日期、四季与二十四节气。

## 当前状态

2026-10-17：六部所供 PDF 共1,843页已逐页读完。现已实现可构建的微信原生试读版及共享核心的网页体验，包含11类场景、52个推荐条目、诗文/英文、日期/四季/24节气、收藏、大字和带参分享。18组自动化测试与手机宽度网页检查通过。官方WXML/WXSS编译及游客模式模拟器运行已验证，修正了原生按钮排列；现已用管理员微信登录真实AppID工程，并成功上传生成手机预览码（代码包486 KB）；手机实际打开、双账号分享与公开发布仍待验证。建议独立包解压到英文目录，本机中文路径存在加载问题。文化内容继续扩充和试读，阅读完成不等于全部史实与字句核验完成。

无需安装npm的[微信开发者工具独立预览包](releases/whattosay-0.1.0-preview.zip)已备好；[导入说明](releases/README.md)。该包供开发预览，尚未微信公开发布。

## 体验与运行

```sh
npm ci
npm run preview
```

打开 http://127.0.0.1:4173 。`npm run build` 构建原生工程，微信开发者工具导入仓库根目录；`npm run package` 生成独立导入zip。完整步骤见 [运行说明](docs/run.md)。

网页预览与微信小程序分别验证；网页不能发送微信分享卡片。

## 技术方向

推荐微信原生小程序（TypeScript + WXML + WXSS）；第一版以有文化依据的本地审核句库、规则筛选和本地收藏完成核心闭环。云端内容更新和 AI 改写按阶段加入，后端优先评估微信·云开发。

这一方向是当前推荐，尚未创建云资源、选择付费套餐或绑定模型供应商。GitHub 托管代码与文档；微信用户使用的是单独构建、预览和发布的小程序。
